# Reid Castillo Photography

Add original photos to `dist/assets/music` or `dist/assets/life`. The folder sets the gallery category. Sharp creates optimized WebP images and a photo list during the Vercel build.

The gallery loads its images before opening. The Contact and Waiting Room pages open directly.

Run `npm install` once. Run `node scripts/preview.js` to preview the site at `http://localhost:8000`.
